# Harbor v1.0.0 开发说明

## 环境要求
- Python 3.10+
- pywebview == 5.4
- PyInstaller

## 安装依赖
pip install pywebview==5.4 pyinstaller

## 本地运行
python main.py

## 打包正常版（2026-10-24 修正：必须用 vendor Python 3.13）
REM 依赖为 cp313 编译版（_cffi_backend/pywin32/PIL pyd），3.15 下编译扩展
REM 全部不可加载——3.15 只能跑纯 Python 测试，构建必须用 vendor 3.13：
set PYTHONPATH=C:\Users\陈\.workbuddy\binaries\python\envs\default\Lib\site-packages
C:\Users\陈\.workbuddy\binaries\python\versions\current\python.exe -m PyInstaller --onefile --windowed --clean --name "Harbor" --icon "harbor.ico" --add-data "harbor.html;." --add-data "libs;libs" main.py --noconfirm
REM 一键三 exe（应用+卸载器+安装器，含载荷 sha256 强校验）：
REM   versions\current\python.exe installer\build_setup.py

## 打包调试版
python -m PyInstaller --onefile --clean --name "Harbor-Debug" --icon "harbor.ico" --add-data "harbor.html;." --add-data "libs;libs" main.py --noconfirm

## 目录结构
- main.py       后端 Python（pywebview API + 工具实现）
- harbor.html 前端单文件（全部 UI + 逻辑）
- harbor.ico  图标
- libs/         前端依赖库（marked / purify / flate / highlight）

## 配置目录
%USERPROFILE%\.glm-chat\

## 运行测试（v1.1 重构后新增）
pip install pytest   # 或使用任意 Python 3.10+ 环境
pytest tests/ -q     # 契约差分测试（legacy vs 重构后逐字节一致）+ 安全修复测试

## 前端源码构建（v1.1 重构后新增）
- 前端源码在 frontend/：index.template.html（骨架）+ src/*.js（按文件名顺序拼接）
- 修改前端后必须重新构建：node frontend/build.js
- 构建产物为根目录 harbor.html（pywebview 加载/打包的就是它）
- 不要直接修改根目录的 harbor.html，改动会在下次构建时被覆盖

## 目录结构（v1.1 重构后）
- main.py            薄入口（装配 + 启动，<60 行）
- backend/           后端包（api.py 门面 + services/ 八个 service + tools_schema.py）
- frontend/          前端源码（模板 + src 模块 + build.js 零依赖构建脚本）
- tests/             pytest 契约差分 + 安全测试（subprocess/ctypes/PIL/webview 全打桩，免 GUI）
- main_v1.0.0_legacy.py / harbor.v1.0.0.html   v1.0.0 原始备份（行为对照基准）
- VERSION            应用版本号单一数据源（自动更新比对用；发版时只改这个文件，勿在代码里手改版本号）

## 发版流程（v1.2 起）
1. 改 VERSION 为目标版本号（如 1.7.1）
2. node frontend/build.js 重建前端
3. pytest tests/ -q 全绿 + python deliverables/design/check_contract.py 通过
4. PyInstaller 打包（VERSION 已随 datas 进包）
5. 在更新源发布 update-manifest.json（version/url/sha256/notes）——
   注意 settings 面板「更新清单地址」：默认源为占位地址，分发前必须配置真实源

## 安装器构建（v1.7 起）
安装器复用产品自身栈（pywebview + 单文件 HTML 向导 + 原生 MessageBox 卸载确认），
零新增工具链；本机构建环境无 tkinter，勿改回 tkinter 方案。

一键构建三个 exe（应用 + 卸载器 + 安装器）：
  python installer/build_setup.py              # 全量
  python installer/build_setup.py --app-only   # 仅应用 exe

产物（dist/）：
  Harbor.exe                    应用本体（onefile，自动更新原地替换它）
  Harbor-Uninstall.exe          卸载器（安装时随包进安装目录，注册表 UninstallString 指向它）
  Harbor-Setup-<version>.exe    安装器（内嵌上面两个，双击=图形向导；/S 静默；--dir 指定目录）

设计口径（外部调研）：每用户安装到 %LOCALAPPDATA%\Programs\Harbor（无 UAC、不阻碍自动更新——
Program Files 会因权限导致自更新失败，行业同款案例）；HKCU 卸载项；用户数据 ~/.glm-chat 卸载默认保留。
核心实现：installer/installer_core.py（可无头单测）+ installer/installer_gui.py（pywebview 向导）
+ installer/setup_main.py（入口，文件名刻意避开 main.py 防 frozen traceback linecache 撞车）。
测试：tests/test_installer.py（核心逻辑 12 项 + 已构建 exe 的端到端静默安装/卸载）。
