3. v1.9.0「放手版」迭代方案

架构调整（一句话）：Agent 主循环从「回合制 ReAct」演进为四段式 Plan（计划契约）→ Act（ReAct+工具+护栏）→ Reflect（自反思环）→ Deliver（校验+摘要+回滚入口）—— 对应系列课程骨架的逻辑层+工程层，落在 Harbor 既有 session 状态机上，不改 js_api 契约。

#任务优先级工作量验收标准
F1Reflexion 自反思环：V1 校验框架扩展「任务级复盘」——完成后本地模型三问（目标达成了吗/有遗漏吗/有副作用吗）→ 结构化 verdict → 不过则补做 ≤2 轮 → 结论进交付摘要P03.0任务完成必产 verdict+confidence；发现遗漏且置信≥0.7 自动补做并标注
F2跨会话记忆系统：append_memory 升级结构化记忆（偏好/项目约定/常用路径）+ 关键词检索注入系统提示 + 用户可查可删P13.0「以后都别用 PowerShell」类偏好跨会话生效；删除后下轮不再注入
F3RAG go/no-go 评估：实测 stdlib sqlite3 的 FTS5 可用性 + 分块/检索质量小样评测 + 结论报告（不做实现）P11.0FTS5 可用性结论 + 3 个测试查询检索质量 + 明确建议
A1-A2自主阶梯基础（任务授权 L2 + 白名单 L4）——引自自主调研，提前至 v1.8.5P03.0授权内工作区写入不弹确认；越界仍拦；白名单可增删
B/C/DPlan-Act + 批量澄清 + 检查点——引自自主调研 v1.9 主件P07.5计划可编辑；重大偏差暂停；快照可回滚

实现步骤

  • v1.8.5（2-3 天）：A1 任务授权 + A2 白名单（guard 扩展）
  • v1.9 W1：B1 Plan-Act 计划生成+todo 状态机（依赖 v1.8 H1）
  • W2：B2 偏差检测 + F1 Reflexion 环（共享「计划基准」）
  • W3：C1 批量澄清 + D1 检查点回滚
  • W4：F2 跨会话记忆（独立，可与 W1 并行）
  • W5：F3 RAG 评估 + 回归 + 发布

预期收益（可证伪）

  • 确认弹窗/任务 -60%（L2 授权+白名单吸收重复批准；审计日志计数验证）
  • 任务结果自检覆盖率 100%（F1 每任务必跑；交付摘要含 verdict 比例验证）
  • 「AI 忘了/跑偏」返工率 -30%（计划契约+偏差检测+自反思三保险）
  • 重复提问成本 token -10%（F2 记忆注入替代重申）
  • 长任务用户中断降至仅重大偏差/高风险
