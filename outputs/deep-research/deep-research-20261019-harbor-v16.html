Harbor v1.6.0「开放版」迭代方案

日期 2026-10-19 ｜ 基线 v1.5.0（561 passed）+ 沙箱核心（584 passed）｜ 总盘子 26–28 人日 ｜ 单人 5–6 周 / 2 人并行 3.5–4 周
输入：交接文档 handover-2026-10-19.md · KNOWN_ISSUES.md · 代码库实测 · 外部检索（GitHub Models）
TL;DR — v1.6.0 把 Harbor 从「本地优先单机客户端」推进到「多云来源 + 可治理执行」： 新增 GitHub Models 免费层接入、DeepSeek 能力校准、五处提示词体系更新、页面信息架构重构， 并收尾沙箱模块（UI + 真机冒烟）与三轮审查遗留的 Agent 问题。
三个关键判断：① 用户点名的「DeepSeek」已经实现（v1.5 preset 完备），本版做实测校准； 真正的接入工作量在 GitHub Models 免费层（端点/鉴权/限额已外部核实）； ② 沙箱后端已交付但无 UI 即无治理，设置面板接线是 P0；③ 布局重构是最大单项（约 5 人日），UI 契约只增不改。

2. M1 · 模型来源扩展与提示词体系（6 人日）

#任务优先级工作量验收标准
T1GitHub Models 预设接入：base_url=https://models.github.ai/inference；Key 文案改「GitHub PAT（models:read）」+ 获取指引；价格置零 + 「免费层」徽标P01.5预设自动填充端点；非法 Key 的 401 人话含 scope 检查指引

T3免费层限额人话映射：429 header 区分「请求频率 vs 每日配额」[外]（源：https://toolchew.com/en/review-github-models-2026）；面板常驻「免费层禁止生产使用」声明 [外]（源：https://toolchew.com/en/review-github-models-2026）P00.5429 人话说明 RPM/日额及恢复时间；限制声明可见
T4DeepSeek 实测校准：真机联调 v4.1-256k 工具调用兼容性 + 价格表校准；结论入交付报告P01.0基准链②工具调用全成功且计费正确；不达预期记录降级路径
T5提示词体系更新（五处）：① 系统提示增「沙箱告知段」② EFFICIENCY_PROMPT 补免费层限额策略 + MCP 铁律 ③ compact 提示增「保留工具调用序列」④ 本地模式段 ⑤ MCP instructions 维持不注入P02.0build_system_prompt 不在逐字节比对清单（安全）；三基准链质量不降（人工 checklist）
接口要点：零新 js_api（T2 优先扩展既有 local_models 语义；差异大则新增 github_models() 进 _V12_EXTRA）； 价格按 v1.2 模型名解析机制，免费层 0 价短路；build_system_prompt 改动沿用 v1.3.2 INTENTIONAL_DELTAS 白名单先例。

8. 待确认问题（产品负责人裁决）

  1. GitHub Models 定位：免费层「明确禁止生产使用」[外]（源：https://toolchew.com/en/review-github-models-2026）——终端用户用免费层跑自己的活儿是否在支持范围？建议接入但明示限制，高频用户引导切付费层。
  2. 布局双轨期：新导航与旧设置浮层并存一版（+0.5 人日）还是直接切换（老入口断流一版）？建议双轨一版。
  3. P2 二选一：遥测最小版（数据治理叙事 + 合规成本）vs DND（轻量体验）——本版只做一个，另一个入 v1.6.1。

[外] 已核实（逐条附来源 URL）：
  • 端点 https://models.github.ai/inference（OpenAI 兼容 chat/completions）；旧 Azure 端点 models.inference.ai.azure.com 已弃用 —— https://toolchew.com/en/review-github-models-2026 ；https://github.blog/ai-and-ml/llms/solving-the-inference-problem-for-open-source-ai-projects-with-github-models/
  • 鉴权：GitHub PAT（classic 或 fine-grained models:read scope）作 Bearer token；Actions 可用内置 GITHUB_TOKEN —— https://github.blog/ai-and-ml/llms/solving-the-inference-problem-for-open-source-ai-projects-with-github-models/ ；https://getfreeai.net/zh-cn/providers/github-models
  • 模型 ID 为 provider/model 格式（如 openai/gpt-4o），裸名报校验错误 —— https://toolchew.com/en/review-github-models-2026
  • 目录接口 GET https://models.github.ai/catalog/models（含 modalities 元数据） —— https://toolchew.com/en/review-github-models-2026
  • 免费层限额：低档约 15 RPM/150 RPD、高档约 10 RPM/50 RPD；429 header 区分频率与日额度；免费层明确禁止生产使用 —— https://toolchew.com/en/review-github-models-2026 ；https://prismix.dev/guides/github-models-guide
