4. 关键流程（合并后）

Plan-Act 主循环（v1.8 在位 + M2 升级）

用户发送
 → hybrid.classify → understand（本地 5s；超时→云端→透传）
 → plan_service.propose → 计划卡先行（Intent Preview：步骤+时间估计+风险+边界声明）
 → 用户批准 / 编辑后批准 / 拒绝
     └─ L2 授权中+全 low 风险 → 自动批准
     └─ 审批预算超限 → 升级任务授权邀请，不继续弹窗
 → Act：五层判定链；browser_* click/fill=always（前后态截图审计）
     └─ validation 失败 → reformulate ≤2 → blocked
 → Reflect：本地 3s → verdict+confidence；<0.7 → 云端复核
 → Deliver：摘要+回滚链接+trace_id 落审计五维链

browser_extract（dual-LLM-lite，双端同一管线）

agent → browser_extract
 → 后端选择（Win WebView2 / macOS WKWebView / headless 兜底）
 → 等待三保险（选择器 ≤8s / DOM 稳定三连稳 / 硬超时+输出校验）
 → 页面 JS 采集 → window.pywebview.api.on_extract(json) 回调（加锁转主队列）
 → dual-LLM-lite 读取器（本地，schema 约束，无指令权）→ 结构化 JSON
 → provenance 包裹（来源 URL + UNTRUSTED DATA）→ 主模型上下文
 → 缓存写入（分级 TTL+适配器版本入键）+ 审计
 → 降级：窗口超时 → headless；验证码 → 面板人工接管
