## 2. 工程铁律（违反=发布事故）

1. **js_api 契约零变更**：`tests/test_api_contract.py` 对 legacy 实例逐字节差分。新增 js_api 必须进 `backend/api.py` 的 `_V12_EXTRA` 集合。
2. **不得污染 config.json**：契约测试比对 config.json。新配置写独立文件（`~/.glm-chat/guard.json`、`mcp_servers.json`）。
3. **前端构建链**：只改 `frontend/index.template.html` + `frontend/src/*.js`（数字前缀决定拼接顺序），`node frontend/build.js` 重建；**禁手改根目录 harbor.html**（会被下次构建覆盖）。
4. **UI 契约**：check_contract.py 五大项只增不改；`__APP_VERSION__` 占位在模板中**只允许出现 1 次**（注释里也不能写这串，会被 split 计数）。
5. **版本号分离**：`API_VERSION='v1.0.0'` 契约钉死；应用版本在 `VERSION` 文件，build 时注入 `APP_VERSION`。
6. **MOTION 令牌纪律**：JS 禁硬编码毫秒（00-motion.js 现读 CSS 变量）；toast dwell 无对应令牌，用 `MOTION.comp()*2` 兜底。

- **A：重复执行/反复弹 cmd 窗** = 去重单槽语义 + 精确字符串键 + open_app 无护栏（三重叠加）。修复后 6 个 xfail 转正。

## 4. 环境与基建要点

- **pytest venv**：`C:\Users\陈\.workbuddy\binaries\python\envs\default\Scripts\python.exe`
- **Node**：`C:\Users\陈\.workbuddy\binaries\node\versions\22.22.2-6\node.exe`
- **本环境限制**：无外网（起窗/exe/更新/端点联调只能自动化到测试层，实测需装机环境）；无 webview/PIL。
- **测试基建坑**（改测试前必读）：
  - legacy `_RT` 是模块级内存，fresh_home 只清文件——比对 legacy 的测试须显式弹出 `_RT` 残留
  - conftest 假剪贴板必须是忠实内存实现（真实 buffer+句柄表）
  - 前端 vm 沙箱 harness：需注入 AbortSignal/TextDecoder 等 Node 全局；DOM 桩必须有 `style:{}`/classList/remove→getElementById 返 null；源文件函数声明会覆盖注入的同名桩（须加载后重注入）
  - admin 临时文件名换 mkstemp 后，从 .bat 内容解析真实路径才是稳定口径
- **GitHub 推送（历史分叉场景）**：远端 commit 若为 API 创建（本地无对象），`git push` 必被拒。解法：远端 tree vs 本地 tree 逐文件 sha 比对 → 差异文件走 Git Data API（blob→tree→commit→PATCH ref），配断点续传状态文件扛大文件超时；网络对 GitHub API 间歇 401，retries≥6。
