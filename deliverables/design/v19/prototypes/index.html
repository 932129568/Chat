使用方式

  • 每个原型自包含（内联 CSS/JS，零外部依赖），双击即可在浏览器打开。
  • 页头右上角可切换亮/暗主题（body.dark）与动效开关（body.fx-off 停列）。
  • 页面底部「演示控制」可重播关键动效链（批准链 / 自动批准 / 检查点三态 / 执行一轮 / 预算推演）。
  • 系统开启「减弱动态效果」时全部装饰动效自动降级（prefers-reduced-motion）。

实现纪律

  • 令牌全部走 var()：v4 既有值原样继承 + 彩格调新令牌（--aurora-5 / --edge-hi-strong / --untrusted / --bg-deep 等）。
  • 新类纯增，不改既有选择器与权重；JS 不硬编码 ms（MOTION 单一事实源读 CSS 令牌）。
  • 动效按方案 §3 分配：模式切换 spring / 批准 anticipate / 回滚 in-soft / stagger 40-60ms 阶梯。
  • glow 白名单：仅批准钮与收回钮 hover；UNTRUSTED 三重编码（色 + 斜纹边 + mono 标注）。
